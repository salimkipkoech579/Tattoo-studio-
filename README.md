🖤 Tattoo Studio Website

A modern, professional, and responsive tattoo studio website designed to showcase tattoo artwork, studio services, artists, pricing, and appointment booking.

✨ Features

- 🏠 Home Page — Attractive hero section with studio branding and call-to-action buttons.
- 🎨 Tattoo Gallery — Showcase completed tattoo designs with categories and filtering.
- 👨‍🎨 Artist Profiles — Display tattoo artists, specialties, experience, and portfolios.
- 💉 Services — Tattoo styles, custom designs, cover-ups, touch-ups, and consultations.
- 💰 Pricing — Clear pricing information and starting prices.
- 📅 Appointment Booking — Customers can request appointments by selecting their preferred date, time, artist, and tattoo service.
- 📱 Responsive Design — Works smoothly on phones, tablets, laptops, and desktop computers.
- ⭐ Testimonials — Customer reviews and experiences.
- 📍 Studio Location — Contact information, location, opening hours, and map integration.
- 📲 Social Media Integration — Links to Instagram, TikTok, Facebook, and WhatsApp.
- 🔐 Admin Dashboard — Manage appointments, artists, gallery images, services, customers, and website content.
- 📧 Notifications — Email/WhatsApp notifications for appointment requests and confirmations.

📅 Booking System

Customers should be able to:

1. Select a tattoo style/service.
2. Choose an artist.
3. Upload a reference image.
4. Describe their tattoo idea.
5. Select preferred date and time.
6. Enter their contact information.
7. Submit the appointment request.
8. Receive a confirmation notification.

🚀 Installation

Clone the project:

git clone https://github.com/salimkipkoech579/Tattoo-studio.git


Navigate into the project
cd tattoo-studio

Install dependencies:

npm install

Start the development server:

npm run dev

⚙️ Environment Variables

Create a ".env" file and configure your application settings:

PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

Never commit your ".env" file to GitHub.
